# Clean-room rebuild record

## Rule

The retired product implementation is treated only as material to remove. TrialBridge TW does not reuse its brand, copy, visual identity, information architecture, assets, prompts, schemas, matching logic, sample personas, videos, screenshots, or component structure.

## Independent inputs

- User-approved product requirements and safety boundaries.
- Public Chrome WebMCP documentation and the public WebMCP reference repository for API behavior only.
- Official TFDA and ClinicalTrials.gov public data interfaces.
- Original TrialBridge TW specifications in this repository.

## Audit

Every milestone runs a retired-brand and legacy-asset scan. Third-party source code is not copied unless separately reviewed, attributed, and licensed. The MIT license in this repository applies to the new implementation and does not waive third-party obligations.
